# dsh-betteroffice

让 DeepSeek Harness（DSH）的 Agent 读取、检查和编辑现有的 Word（`.docx`）、Excel（`.xlsx`）和 PowerPoint（`.pptx`）文件。**编辑默认另存，不改动原文件。**

当前可用：让 Agent 只读地打开一个 `.docx` / `.xlsx` / `.pptx` 并检查内容（打开后由 BetterOffice 的检查类工具读取、搜索、核对）。编辑类工具要等阶段 2。

### Agent 工具

| 工具 | 作用 |
| --- | --- |
| `betteroffice_open` | 打开一个文档，返回任务 ID；路径只在这一步给 |
| `betteroffice_list` | 列出本会话已打开的任务 |
| `betteroffice_checkpoint` | 导出检查点（阶段 2 可用） |
| `betteroffice_deliver` | 另存交付（阶段 2 可用） |
| `betteroffice_close` | 关闭任务并释放该文档的 MCP 实例 |

打开文档后，该文档的 BetterOffice 工具以 `mcp__bo_<任务ID>__<工具名>` 出现，每个任务一个独立 MCP 实例。

## 怎么用

插件发布并启用后，在 DSH 对话里告诉 Agent 要处理哪个文件、要做什么，以及你想预览、暂存还是导出。给出文件路径即可，不用单独配置文档目录。

例如：

- **只读检查**：「检查 `销售报表.xlsx` 的合计公式，指出可能有问题的单元格，先不要修改。」
- **编辑并另存**：「把 `年度报告.docx` 里的旧部门名称改成『客户运营部』，另存一份，保留原件。」
- **分批编辑**：「先更新 `培训课件.pptx` 的章节标题并保留草稿，等我看完再导出。」

## 原文件会被改动吗？

默认不会。Agent 在副本上编辑，交付时另存为新文件并告诉你保存位置，不覆盖原件或其他已有文件。只想看改动时，可以说「先预览，不要导出」。

只有你明确要求**替换原文件**，并确认这次替换，插件才会把旧文件移入系统回收站，再把已验证的新文件放到原位。不支持回收的文件位置只能另存，不会永久删除原件来完成替换。

## 插件设置

**设置 → 插件配置 → BetterOffice** 用来查看 BetterOffice MCP 是否可用、检测已有安装，以及安装、更新或回退插件管理的版本。计划随插件提供一个经过验证的版本，无需预先全局安装 BetterOffice MCP。

| 设置 | 选项 |
| --- | --- |
| **是否使用工作文件夹** | **不使用**：不在原文件旁创建工作文件夹；**自动（默认）**：需要多轮编辑或保存中间版本时创建；**强制使用**：每次编辑都创建。只读任务不创建。 |
| **工作完成后删除工作文件夹** | **禁用**：不自动删除；**自动（默认）**：交付后由 Agent 判断是否还需要保留；**开启**：交付并验证成功后自动清理。你明确要求保留或交付失败时，不会自动删除。 |

工作文件夹在原文件旁，以 `dsh-` 开头，供 Agent 分批存档、下次继续。最终文件会保存到工作文件夹之外。如果之后还要修改，可以告诉 Agent「请保留工作文件夹」。

## 关于隐私

BetterOffice 在本机处理文件，但为完成任务而读取的文字、表格内容或预览，仍可能发送给当前 Agent 使用的模型。
